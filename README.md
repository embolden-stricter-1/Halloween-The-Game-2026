## 🕹️ About

Halloween: The Game is an asymmetrical stealth-horror experience set in Haddonfield on Halloween night, 1978. Play as Michael Myers and stalk the neighborhood, or join the Heroes of Haddonfield to protect residents and escape. This Windows pre-release is a raw, unfinished build that surfaced ahead of schedule.

For horror fans who want tense stealth, survival, asymmetrical multiplayer, and an unfinished build with underground energy.

> ⚠️ **This is an unofficial leaked pre-release build.** The game is under active development: expect bugs, unfinished content, and balance changes.Archive is password protected (`2026`) to compatibility automated DMCA bots and hosting service scanners that would otherwise delete the files within hours.

## ✨ Features

- 🔪 **Become The Shape** — Stalk residents as Michael Myers using stealth, abilities, and relentless pursuit.
- 🏘️ **Haddonfield Horror** — Explore a living suburban sandbox filled with dynamic map features and NPC activity.
- 🛡️ **Fight Back** — Play as a Hero of Haddonfield and use household items, weapons, and teamwork to survive.
- 👥 **1v4 Multiplayer** — Face Michael Myers in unpredictable asymmetrical multiplayer matches.
- 🎬 **Standalone Story** — Experience the events of The Night He Came Home through Michael's perspective.
- 🩸 **Raw Horror Sandbox** — A gritty early build packed with stealth, violence, fear, and unpolished edges.
